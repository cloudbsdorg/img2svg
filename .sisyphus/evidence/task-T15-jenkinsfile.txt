=== Jenkinsfile matrix block (lines 85-111) ===

    stage('Backend Matrix') {
        matrix {
            axes {
                axis {
                    name 'BACKEND'
                    values 'cpu', 'nvidia', 'amd', 'apple'
                }
            }
            stages {
                stage('Install') {
                    steps {
                        sh 'uv pip install ".[$BACKEND]"'
                    }
                }
                stage('Test') {
                    steps {
                        sh 'uv run pytest -m "not slow" -q'
                    }
                }
                stage('Verify Backend') {
                    steps {
                        sh 'bash scripts/verify_backend.sh $BACKEND'
                    }
                }
            }
        }
    }

The matrix inherits `agent any` from the pipeline top level. Per-vendor
gating (apple on macos, amd on amd-gpu, nvidia on nvidia-gpu) is enforced
by the verify_backend.sh step rather than by per-cell agent labels, so
a single generic Linux agent is enough to exercise the cpu/nvidia/amd
logic and a macos agent picks up the apple cell.

The 6th new stage "Backend Matrix" was added at the end.

=== Summary of changes ===

1. scripts/verify_backend.sh: new file (137 lines)
   - BSD-3-Clause header
   - shebang: #!/usr/bin/env bash
   - set -euo pipefail
   - Anchors to project root via cd "$(dirname "$0")/.."
   - Validates expected arg (one of cpu, nvidia, amd, apple)
   - Detects via uv run python -c "from img2svg.backends import REGISTRY; print(REGISTRY.detect().type().value)"
   - Maps nvidia -> cuda, apple -> mps
   - amd accepts cuda (ROCm PyTorch exposes CUDA API)
   - cpu is strict (CPU is fallback, not priority)
   - Exits 0 on match, 1 on mismatch, 2 on bad arg, 3 on detection failure
   - Does NOT call platform.system()

2. Jenkinsfile: added Backend Matrix stage (lines 75-111)
   - Uses matrix-project plugin (no new plugins required)
   - Axis: BACKEND with values 'cpu', 'nvidia', 'amd', 'apple'
   - Three matrix sub-stages: Install, Test, Verify Backend
   - Install: uv pip install ".[$BACKEND]"
   - Test: uv run pytest -m "not slow" -q
   - Verify Backend: bash scripts/verify_backend.sh $BACKEND
   - Inherits agent any from pipeline top (no per-cell agent override)
   - All 6 existing stages preserved unchanged
   - 30 MINUTES timeout preserved
