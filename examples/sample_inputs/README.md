# Sample Inputs

The before/after gallery in [`../before_after.md`](../before_after.md) uses two synthetic test fixtures from the project's test suite. They live in `tests/fixtures/` and are small, deterministic, and safe to commit.

| File | Size | What it is | Classification |
| ---- | ---- | ---------- | -------------- |
| [`logo.png`](../../../tests/fixtures/logo.png) | 1.3 KB | 200×200, three flat-color shapes (red square, blue triangle, black circle) on white | `photo` (heuristic) |
| [`diagram.png`](../../../tests/fixtures/diagram.png) | 1.5 KB | 200×200 schematic, a few labeled rectangles and connector lines on white | `diagram` (heuristic) |

Both are generated by `scripts/gen_test_images.py` (run automatically by `tests/conftest.py` when missing). They are the smallest inputs that exercise the four renderers without pulling in any external imagery, which keeps the example SVGs reproducible and the gallery diff-friendly.

The full output set is in [`../sample_outputs/`](../sample_outputs/): 4 modes (`labels`, `visual`, `annotated`, `trace`) × 2 fixtures = 8 SVGs, each paired with a `.json` sidecar.
